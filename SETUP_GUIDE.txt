# Hari Krishna Exports AI Chatbot - Setup Guide

## 🚀 Quick Start

### 1. Environment Setup
Create a `.env` file in the root directory with the following variables:

```env
# MongoDB Connection
MONGO_URI=mongodb+srv://username:password@cluster.mongodb.net/hk-chatbot?retryWrites=true&w=majority

# OpenAI API Key
OPENAI_API_KEY=sk-your-openai-api-key-here

# Website Configuration
BASE_URL=https://www.hk.co

# CORS Origins (comma-separated)
ALLOWED_ORIGINS=http://localhost:8080

# Server Configuration
PORT=8080
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Database Setup
- Create a MongoDB Atlas account
- Create a new cluster and database
- Update the `MONGO_URI` in your `.env` file

### 4. Scrape Website Content
```bash
npm run scrape
```
This will crawl the HK.co website and extract all content for AI training.

### 5. Seed FAQ Data
```bash
npm run ingest
```
This will populate the database with comprehensive company-specific FAQ data.

### 6. Start the Server
```bash
npm run dev
```
The API will be available at `http://localhost:8080`

## 🔧 Customization

### Adding New FAQ Entries
Edit `scripts/ingest.js` and add to the `seed` array:

```javascript
{
  key: 'your_topic',
  question: 'User question',
  answer: 'Company response',
  options: ['Option 1', 'Option 2', 'Back to main menu']
}
```

### Modifying AI Behavior
Edit `src/services/ai.js` to update the system prompt and response guidelines.

### Adjusting Scraping Parameters
Modify `src/scraper/scrape.js` for:
- Maximum pages to scrape
- Scraping delays
- URL filtering rules

## 🆘 Troubleshooting

### Common Issues
1. **MongoDB Connection Failed** - Check MONGO_URI format
2. **OpenAI API Errors** - Verify API key validity
3. **CORS Issues** - Update ALLOWED_ORIGINS
4. **Scraping Timeouts** - Increase timeout values if needed
